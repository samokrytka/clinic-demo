# Zub Clinic — демо Mini App

Пример интерфейса Telegram Mini App для стоматологической клиники:
услуги, специалисты, выбор времени, демонстрационные записи, перенос и отмена.

Демо: https://samokrytka.github.io/clinic-demo/

Данные специалистов, отзывы и расписание демонстрационные. Записи сохраняются
только в браузере и не отправляются в настоящую клинику.

Этот репозиторий содержит только публичный интерфейс и используемые им
изображения. Серверный код бота, API, ключи и база данных сюда не входят.

## GitHub Pages

В Settings → Pages выберите Deploy from a branch, ветку main и папку / (root).
Для обновления заменяйте index.html и используемые файлы в assets/.

Полный проект хранится отдельно в приватном репозитории.
